# OpenXML1

Development workspace for recompiling the PlayStation 2 release of X-Men Legends with PS2Recomp.

This repository tracks reproducible analysis configuration, helper scripts, and project notes. It intentionally excludes the game ISO, extracted disc contents, generated C++ output, build products, probe captures, and dependency checkouts.

Runtime and recompiler changes are developed in the `GTTeancum/PS2Recomp` fork and proposed upstream as focused pull requests.
